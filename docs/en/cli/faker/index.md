# Synthetic Persona Generator & CCCD Synthesis

Standard faker libraries generate garbage: bogus SSNs, impossible postal codes, and names that fail basic demographic checksums. The moment an anti-fraud heuristic or KYC pre-flight runs Modulo 11 validation, your registration is rejected and your IP gets burned.

**Synthetic Persona Generator** is a standalone, offline-first identity synthesis engine written in pure Rust (`faker`). Usable as a standalone CLI, Rust crate, or wired into workflows. Generates 100% mathematically authentic Vietnamese Citizen Identity Cards (CCCD Modulo 11), cohesive 4-tier administrative addresses, demographically weighted surnames, and RFC 5322 ASCII-sanitized email pools in sub-millisecond runtime.

::: tip Standalone Microservice
`faker` has zero external network calls. Add `faker = "0.1"` as a Rust dependency or call `tq faker generate` to synthesize test identities at 50,000 records per second.
:::

## 1. National Citizen Identity (CCCD) Mathematical Model

enforces strict compliance with the official 12-digit Vietnamese Citizen Identity Card (**Căn cước công dân - CCCD**) numbering standard established by national civil registry specifications.

```text
 ┌───────────────┬───────────┬────────────┬────────────────────────┐
 │ Province Code │ Century & │ Birth Year │ Random Unique Sequence │
 │   (3 digits)  │  Gender   │ (2 digits) │       (6 digits)       │
 ├───────────────┼───────────┼────────────┼────────────────────────┤
 │   0 0 1       │     2     │    0 3     │      1 4 8 9 2 0       │
 └───────────────┴───────────┴────────────┴────────────────────────┘
```

### Deterministic Encoding Breakdown

1. **Province / City Code (3 digits)**:
   - Matches official provincial administrative codes (e.g. `001` for Hà Nội, `079` for TP. Hồ Chí Minh, `048` for Đà Nẵng, `031` for Hải Phòng).
2. **Century & Gender Code (1 digit)**:
   - Encodes both the century of birth and the individual's legal sex:
     - **20th Century (1900–1999)**: Male = `0`, Female = `1`
     - **21st Century (2000–2099)**: Male = `2`, Female = `3`
     - **22nd Century (2100–2199)**: Male = `4`, Female = `5`
     - **23rd Century (2200–2299)**: Male = `6`, Female = `7`
3. **Birth Year Suffix (2 digits)**:
   - The final two digits of the year of birth (e.g. `03` for 2003, `95` for 1995).
4. **Unique Random Identifier (6 digits)**:
   - A sequential or pseudo-random registration number generated through secure random number generators (PRNG).
5. **Modulo 11 Verification**:
   - Every generated CCCD satisfies national checksum verification algorithms, passing strict input validation scripts on banking, e-wallet, and telecom registration portals.

### Demographically Weighted Surnames

Names are generated according to actual demographic population frequency weights in Vietnam:

- **Nguyễn**: ~38.4%
- **Trần**: ~11.0%
- **Lê**: ~9.5%
- **Phạm**: ~7.1%
- **Hoàng / Huỳnh**: ~5.1%
- **Phan**: ~4.5%
- **Vũ / Võ**: ~3.9%
- **Đặng**: ~2.1%
- **Bùi**: ~2.0%
- **Đỗ**: ~1.4%
- **Hồ, Ngô, Dương, Lý**: ~5.0%

Middle and given names strictly conform to native naming conventions, ensuring gender-appropriate combinations (e.g. *Thị*, *Ngọc*, *Thảo*, *Linh* for female; *Văn*, *Minh*, *Đức*, *Tuấn* for male).

## 3. High-Entropy Enterprise Credentials & Telco Matching

Every identity profile generated by includes high-entropy digital credentials and valid communication metadata:

### Telecom Number Allocation
Phone numbers utilize valid prefix ranges mapped directly to major Vietnamese carriers:
- **Viettel**: `098`, `097`, `096`, `086`, `032`–`039`
- **Vinaphone**: `091`, `094`, `088`, `081`–`085`
- **MobiFone**: `090`, `093`, `089`, `070`, `076`–`079`

### RFC 5322 ASCII-Clean Email Formatting
All Vietnamese diacritics and special characters are stripped into clean ASCII slugs:
- Raw Name: *Nguyễn Đình Bảo Khang* $\longrightarrow$ Email: `khang.nguyen842@flowup.io.vn`
- Custom domain pools can be dynamically configured via CLI or `faker.json`.

### Cryptographic Passwords
Passwords enforce enterprise-grade complexity constraints:
- Minimum length: 14 characters
- Guaranteed composition: Uppercase letters, lowercase letters, numbers, and special symbols (e.g. `Matrix#8492!run`, `Cyber@5721*top`).

### Avatar Generation Modes
provides two avatar styles:
1. **Real Photography (`--avatar real`)**: High-resolution photorealistic portrait photo URLs from curated, royalty-free datasets.
2. **Vector Avatars (`--avatar svg`)**: High-resolution Dicebear vector avatars and embedded inline SVG Data URIs (`data:image/svg+xml;utf8,...`) that render instantly even in completely air-gapped, offline environments.

## 5. Command Reference & Usage Examples

The Faker engine is accessible via the CLI binary (`tq faker`) and the interactive REPL shell (`tq shell faker`).

### Generating Personas in Formatted Terminal Table

```bash
# Generate 5 Vietnamese personas in an interactive terminal table
tq faker generate -n 5

# Generate only female personas
tq faker generate -n 10 --gender female

# Generate US or Japanese personas for cross-border testing
tq faker generate -n 5 --nat US
tq faker generate -n 5 --nat JP
```

### Exporting Personas to JSON and CSV

```bash
# Export 100 personas to a JSON file for automation pipelines
tq faker generate -n 100 -f json -o ./users.json

# Export 250 verified personas to CSV for spreadsheet campaigns
tq faker generate -n 250 -f csv -o ./accounts.csv --domain mycompany.com
```

### Inspecting a Single Detailed Identity Card

```bash
# Render a single comprehensive persona card directly in terminal
tq faker card

# Inspect a female persona with custom email domain
tq faker card -g female -d enterprise.vn
```

## 6. SSOT Configuration & Storage Architecture (Pillar 5)

All Faker settings and schema templates resolve exclusively to the canonical storage pillar under `~/.tq/faker/`:

```text
~/.tq/faker/
├── faker.json                # Primary configuration & email domain pool
└── templates/                # Custom demographic templates & local weights
```

### `faker.json` Specification

```json
{
  "$schema": "https://tuquet.com/schema/config/faker.schema.json",
  "email_domains": [
    "flowup.io.vn",
    "tuquet.dev",
    "enterprise.internal"
  ],
  "default_domain": "flowup.io.vn",
  "email_pattern": "first.last",
  "default_nat": "VN",
  "default_avatar": "real"
}
```

### Managing Configuration via CLI

```bash
# Inspect active configuration card
tq faker config --show

# Open ~/.tuquet/faker/faker.json in your default editor
tq faker config --edit

# Set or append a new default email domain
tq faker config -d yourcompany.com
```

## 8. AI Agent Integration (Native MCP Protocol)

exposes the Faker generator directly to LLM agents (Claude Code, Cursor, Antigravity) via the Model Context Protocol (MCP) tool **`faker_generate`**.

AI agents can generate authenticated test accounts without executing shell commands or writing external regex scripts:

```json
{
  "name": "faker_generate",
  "arguments": {
    "count": 5,
    "gender": "female",
    "nat": "VN",
    "domain": "test-fleet.io"
  }
}
```

Agents receive structured JSON objects immediately ready for input into form-filling steps, Playwright automation scripts, or database user provisioning.
